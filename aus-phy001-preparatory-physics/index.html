Week 1

📘 Week 1 — Units & Measurement

▼

💡 Concept Summary

▼
SI Base Units The International System of Units defines 7 base units. The most common in mechanics: metre (m), kilogram (kg), second (s), and ampere (A).
Significant Figures The number of meaningful digits in a measured value. Non-zero digits are always significant. Zeros between non-zero digits are significant. Leading zeros are never significant.
Scientific Notation A way to express very large or small numbers: a × 10ⁿ, where 1 ≤ a < 10.

Students commonly confuse precision with accuracy. Emphasize the dartboard analogy — precise = clustered, accurate = near the bullseye. Also: many students miscount sig figs with zeros. Spend time on the 3 zero rules before moving on.

📝 Worked Example

▼
Example
Convert 72 km/h to m/s. Show your working using the factor-label method.
Step 1 — Write down what you're converting ▼
Start: 72 km/h
Target: ? m/s
Step 2 — Set up conversion fractions ▼
72 km/h × (1000 m / 1 km) × (1 h / 3600 s)

The km cancels and the h cancels.
Step 3 — Calculate ▼
72 × 1000 / 3600 = 20 m/s

✅ Answer: 20 m/s

Common error: students divide by 1000 instead of multiplying. Encourage them to always write out the full factor-label chain before calculating. Reinforce that units behave like algebra.

🔘 Multiple Choice Questions

▼
MCQ · L1
How many significant figures are in the number 0.00304?
A 2
B 3
C 5
D 6
Start by ignoring all leading zeros. Count only from the first non-zero digit onward.
Teacher note: The zero between 3 and 4 is the most commonly missed sig fig. Reinforce: "zeros sandwiched between non-zero digits are always significant."

✅ True / False

▼
True / False
The kilogram is an SI base unit for weight.

This distinction is critical for later chapters. Mass is an intrinsic property; weight depends on gravitational field strength. Use Fg = mg to connect them.

⚠️ Common Mistakes

▼
Mistake #1
Counting leading zeros as significant figures (e.g. saying 0.0045 has 4 sig figs).
Only start counting from the first non-zero digit. 0.0045 has 2 sig figs.
Mistake #2
Flipping the conversion fraction (e.g. multiplying by h/3600 instead of 3600s/h).
Write out the unit you want to cancel on the bottom of the fraction.

Week 2

📗 Week 2 — Kinematics (1D)

▼

💡 Concept Summary

▼
Displacement vs Distance Displacement is a vector — it depends only on start and end positions. Distance is scalar — total path length.
SUVAT Variables s = displacement  |  u = initial velocity  |  v = final velocity  |  a = acceleration  |  t = time
Emphasise direction conventions. Set up +/− axis early. Students confuse "decelerating" with "negative acceleration" — they are only the same if the object is moving in the + direction.

📐 SUVAT Equations

▼
Equation 1
v = u + at
no s
Equation 2
s = ut + ½at²
no v
Equation 3
v² = u² + 2as
no t
Equation 4
s = ½(u+v)t
no a
Teach students to always list the 5 SUVAT variables first, circle the unknown, and pick the equation that has exactly 3 knowns + the unknown.

Week 3

📙 Week 3 — Vectors & Forces

▼

💡 Concept Summary

▼
Vectors vs Scalars Vectors have both magnitude and direction (e.g. force, velocity, displacement). Scalars have magnitude only (e.g. speed, distance, mass).
Newton's First Law An object remains at rest or in uniform motion unless acted upon by a net external force.
Newton's Second Law The net force on an object equals its mass times acceleration: Fnet = ma.
For FBD (free body diagrams): use strictly vertical arrows for vertical force problems. Common student error is drawing the normal force at an angle. Reinforce: N and Fg are always vertical.

How to Add a New Week

▼
  1. Open index.html in any text editor (VS Code recommended).
  2. Find the comment <!-- WEEK 4 SLOT --> (placed at the end of Week 3 section).
  3. Copy the entire Week 1 <div class="card">...</div> block.
  4. Paste it after the Week 3 card.
  5. Update the id attributes to week4-card, w4-concepts, etc.
  6. Add your content to the WEEK_TEMPLATE_SYSTEM JS object (see Template Panel).
  7. Add a nav link in #sidenav: <a href="#week4" class="nav-link">📓 Week 4</a>.
  8. Add a card to the home week-nav-grid.
  9. Save and open in browser — no build step needed.

How to Add Quiz Questions

▼

Find the QUIZ_BANKS object in the JavaScript section. Each quiz is an array of question objects. Follow this structure:

{
  q: "Question text here?",
  type: "mcq",            // mcq | tf | numeric
  options: ["A","B","C","D"],
  correct: 1,             // index (0-based)
  explanation: "Why this answer is correct.",
  teacherNote: "Common mistake or teaching tip."
}

Then call renderQuiz('quiz-container-id', 'quiz-bank-key') to mount it.

How to Add MCQs to a Week

▼
  1. Find the MCQ subcard for the target week (e.g. id="w1-mcq").
  2. Add a new <div class="q-item" id="mcq-w1-X"> block.
  3. Add .mcq-options with data-correct="B" and data-explanation="...".
  4. Add a <div class="feedback" id="mcq-w1-X-fb"></div>.
  5. No JS changes needed — the MCQ engine auto-detects all .mcq-options containers on page load.
